# 建行杯小程序

“纸韵蛙鸣·哈什蚂传奇”微信小程序。项目当前处于第一阶段：完成核心信息架构、页面骨架、服务层和本地 mock 运行链路。

## 本地运行

1. 使用微信开发者工具打开项目根目录。
2. 确认 `project.config.json` 中的 AppID 属于当前开发团队。
3. 当前环境默认使用 `config/env.js` 的 `development` 配置和本地 mock 数据，不会调用未配置的后端地址。
4. 后端接口准备好后，在 `config/env.js` 中切换环境并填写 `baseUrl`，再关闭 `useMock`。

## 目录约定

- `pages/`：页面和页面级交互
- `services/`：业务服务和 API 适配，不在 WXML/页面中直接拼接口
- `utils/`：请求、鉴权、本地存储等通用能力
- `config/`：环境配置
- `constants/`：稳定的业务枚举和导航元数据
- `docs/`：需求拆解、接口契约和工程约定

## 开发约束

- 页面不得直接调用 `wx.request`，统一使用 `services/`。
- 不把 Token、AppSecret、支付证书等敏感信息提交到仓库。
- 后端接口以 `docs/api-contract.md` 为最小契约，字段变更先更新契约再改页面。
- 付费、公益、二维码核销和排行榜上线前必须经过后端、隐私和合规评审。
