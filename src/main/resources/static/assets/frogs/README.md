# 林蛙运行时素材

这里仅放可以直接被 Spring Boot 静态资源处理器读取的 PNG 预览图。原始压缩包、PSD/PSB/文档等设计源文件仍保留在项目根目录的 `F` 文件夹，不参与运行时发布。

九张运行时预览图统一为 1024x1024 透明 PNG，并按有效 Alpha 内容边界归一化留白，避免近乎透明的残留像素把画布撑大，保证角色墙中不同林蛙的视觉占比一致；这不会改变原始设计文件。

接口 `GET /v1/content/frogs` 返回稳定的 `assetKey` 和 `assetUrl`。本地默认 URL 为 `/assets/frogs/{id}.png`；部署到 OSS/CDN 时，通过 `ASSET_BASE_URL` 配置公共前缀即可，不需要修改数据库字段或小程序代码。

冬眠蛙预览图由原始包中的主体、边框线稿、边框三个透明图层按原始 1024x1024 画布合成，保留设计稿的完整剪纸边框。
