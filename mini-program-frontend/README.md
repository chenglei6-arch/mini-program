# 建行杯小程序

“纸韵蛙鸣·哈什蚂传奇”微信小程序。项目当前处于开发阶段，页面通过服务层接入后端接口，未接入的功能显示“开发中”。

## 本地运行

1. 使用微信开发者工具打开项目根目录。
2. 确认 `project.config.json` 中的 AppID 属于当前开发团队。
3. 当前开发环境通过 `config/env.js` 的 `development` 配置连接本地后端。
4. 后端接口准备好后，在 `config/env.js` 中填写可被设备访问的 `baseUrl`。

## 真机联调

真机不能访问电脑上的 `localhost`。如果要在真机请求本地后端：

1. 让手机和电脑连接同一个局域网，并将 `baseUrl` 改为电脑局域网 IP，例如 `http://192.168.1.3:8080`。
2. 确认后端监听外部地址、Windows 防火墙允许 8080 端口，并在手机浏览器访问 `/v1/system/ping` 验证连通性。
3. 在微信开发者工具中开启“不校验合法域名、TLS 版本以及 HTTPS 证书”后重新编译并预览；正式环境必须使用已配置的 HTTPS 合法域名。

## 目录约定

- `pages/`：页面和页面级交互
- `services/`：业务服务和 API 适配，不在 WXML/页面中直接拼接口
- `utils/`：请求、鉴权、本地存储等通用能力
- `config/`：环境配置
- `constants/`：稳定的业务枚举和导航元数据
- `docs/`：需求拆解、接口契约和工程约定

## 开发约束

- 页面不得直接调用 `wx.request`，统一使用 `services/`。
- 不把 Token、AppSecret、支付证书等敏感信息提交到仓库。
- 后端接口以 `docs/api-contract.md` 为最小契约，字段变更先更新契约再改页面。
- 付费、公益、二维码核销和排行榜上线前必须经过后端、隐私和合规评审。
