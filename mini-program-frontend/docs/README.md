# 守护神游戏

摇一摇抽奖游戏，收集9只林蛙守护神。

## 快速开始

### 启动后端
```bash
cd mini-program-backend
./gradlew bootRun
```

### 启动前端
1. 打开微信开发者工具
2. 导入 `mini-program-frontend` 目录
3. 进入守护神页面测试

## 文档

- **前端开发文档：** `mini-program-frontend/docs/guardian-game.md`
- **后端测试文档：** `mini-program-backend/docs/guardian-game-test.md`

## 核心规则

- 每天基础3次，分享+1次
- 零点自动重置（Asia/Shanghai）
- 优先抽未收集角色
- 答错不扣次数
- 收集1/3/9只解锁铜/银/金徽章
