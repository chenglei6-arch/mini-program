# 第一阶段交付边界

## 已完成

- Git 本地仓库初始化并配置 `origin` 远端。
- 原生小程序环境配置和后端服务切换。
- 请求层：统一 URL、鉴权头、超时、HTTP 错误和业务错误归一化。
- 鉴权层：微信登录入口、Token 存储、会话失效清理。
- 服务层：首页、游戏事件、扫码核销、用户资料、公益摘要、排行榜。
- 页面骨架：首页、三款游戏、扫码解锁、公益、排行榜、用户中心。
- 微信能力接入边界：`wx.login`、`chooseAvatar`、昵称填写、`scanCode`、`vibrateShort`、分享回调。
- 未接入后端的功能统一显示“开发中”，不在前端维护演示数据。

## 需要外部输入后才能完成

1. Apifox 导出接口契约：请求/响应、错误码、鉴权和分页规则。
2. 后端环境：开发、测试、生产域名，以及微信服务器域名白名单。
3. 内容资产：九只林蛙、五款纹样、故事文本、音频、动画、品牌字体和正式图片。
4. 商品与支付：盲盒 SKU、库存、价格、物流、退款、商户号和支付回调方案。
5. 二维码规则：生成、绑定、核销、重复使用、退货和异常补发策略。
6. 公益合规：捐赠主体、资金凭证、报告审核和公示频率。

## 第一阶段验收建议

- 微信开发者工具可启动并访问所有已登记页面。
- 所有已启用服务方法都有对应的 Apifox 请求和错误码测试。
- 页面只依赖服务返回的稳定字段，不读取后端原始响应。
- 登录、扫码、支付、分享、相册写入和隐私授权均有拒绝/取消分支。
- 至少覆盖 iOS、Android、低端设备、弱网和重复点击场景。
